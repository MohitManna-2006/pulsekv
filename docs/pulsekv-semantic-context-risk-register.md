# PulseKV v3 / Phase 10 — Risk Register

**Status:** originally derived from the design and implementation plan alone,
before any code existed. As of Phase 10.4 (equivalence guard + evaluation
corpus, complete), row 1 — the register's highest-impact entry — is updated
with real measured evidence rather than a structural estimate; row 16 was

production observability or performance-economics risks. Other probability

## Notes on rating methodology

Probability ratings above are qualitative and design-time — this project's
own stated discipline (master prompt §40: "if you claim a number, measure it
or label it a hypothesis") applies to risk ratings as much as to latency
claims. None of the probability/impact labels above should be read as
calibrated percentages; they are relative orderings meant to prioritize
Phase 10.4's corpus-building and Phase 10.8's benchmarking effort, which are
the two phases that convert most of this register from hypothesis to
evidence.
